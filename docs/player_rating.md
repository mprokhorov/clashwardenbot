# Рейтинг игроков (`/player_rating`)

Авторитетное ТЗ, сформулированное пользователем (июль 2026), и статус реализации в `claude/dev`.
Реализация: `DatabaseManager.get_player_ratings()` + `routers/player_rating.py`.

## ТЗ (слова пользователя, источник истины)

### 1. Допуск к розыгрышу
Пороги среднего числа звёзд ЛВК по разнице с максимальным ТХ (Макс / −1 / −2 / −3 и ниже)
и минимум войн ЛВК — хранятся в `player_rating_config` (ключ — корневой клан семейства):

- Montilian Twink — 2.5+ / 2.4+ / 2.1+ / 2.0+ — минимум 5 войн ЛВК
- King — 2.6+ / 2.4+ / 2.1+ / 2.0+ — минимум 4 войны
- Бурилы — 2.8+ / 2.6+ / 2.1+ / 2.0+ — минимум 3 войны

Максимальный ТХ определяется просто: максимум по таблицам `player` и `opponent_player`
(`get_max_town_hall_level()`); позже планируется заменить на честную функцию.

В ЛВК для допуска и среднего учитываются только **начавшиеся** войны, в которых игрок участвует.
При двух ЛВК в сезоне средние звёзды остаются, а минимум войн умножается на 2.

### 2. ЛВК — до 60 очков
`очки = звёзды / 21 × 55 (+5 за 21+ звезду)`.

### 3. Лига — до 30 очков
За лигу (по дневным показаниям): 36 — 20, 35 — 15, 34 — 10, 33 — 5, 32 — 3, 31 — 1 очко.
За место в клане: только среди допущенных; `10 × (N − место) / (N − 1)`; единственный допущенный
получает 10 автоматически; при равенстве лиги и кубков игроки делят усреднённое место
(места 5–8 → все считаются как (5+8)/2).

Механика: каждый день для каждого игрока сохраняется лучшее показание (лига, кубки) —
таблица `player_league`, пишут все боты семейства; игрок может засветиться в нескольких кланах
семейства (берём лучшее показание за день). За каждый день считаются очки лиги и места,
итог делится на количество дней в календарном месяце. Дни без записи игрока не приносят очков.

### 4. Рейды — до 10 очков
`очки за атаки = атаки / 6 × 3`. Золото: среднее по всем сыгранным аккаунтам человека
(связь аккаунтов — `player_bot_user`), применяется к каждому аккаунту одинаково.
Пороги золота: 10k−15k−20k−25k−30k−40k−50k → 1−2−3−4−5−6−7 очков (ниже 10k — 0).

### 5. КВ — только штрафы
1 атака: −1, 0 атак: −3 (данные в `cw_bonus[кол-во атак]`, из конфига). Только завершённые войны.

### Семейство кланов
`child_clan` задаёт семейство. Рейтинг одинаков из любого клана семейства (код находит корень:
отца, если клан — чей-то ребёнок). Рейды и КВ учитываются со всех кланов семейства
(играются максимум в одном клане одновременно). Сезон = календарный месяц. Рейтинг в сезоне
существует, если хотя бы у одного игрока есть записи лиги/кубков за месяц.

### Отображение
Показываются игроки, находящиеся в семействе на момент запроса, с ненулевым рейтингом.
По умолчанию — только допущенные; если допущенных нет — все. Кнопки: верхний ряд
«📋 Подробнее», «🔽 Развернуть / 🔼 Свернуть», «🔄 Обновить»; нижний ряд «⬅️ <прошлый сезон>»,
«➡️ <следующий сезон>» (если существуют), «🧾 Все сезоны». Карточка «Подробнее» — формат
см. `player_rating_details()` (сверен с примером пользователя).

## Решения, ПОДТВЕРЖДЁННЫЕ пользователем/данными
- Конфиг в проде: массивы порогов длины 4, `cw_bonus = {-3, -1, 0}` (индекс = число атак, 2+ → 0).
- Семейство в проде: Montilian Twink `#2PGYGGRJQ` (корень) + King `#PGVGUUCL` +
  Бурилы `#2YV092GQY` + Бурилы 2.0 `#2LG2RLLV9`. Montilian Ore удалён из семейства.
- Сбор `player_league` начат 2026-05-26/27 ⇒ май 2026 — «урезанный» сезон (~5/31 лиговых очков).
- Бурилы не играли ЛВК в июле 2026 — отсутствие данных корректно.

## Решения, взятые из claude/main — ТРЕБУЮТ ПОДТВЕРЖДЕНИЯ пользователя
(claude/main может содержать неверные интерпретации — не считать её источником истины)

1. **Автодопуск кланов без ЛВК-требований**: у Бурил 2.0 в конфиге NULL-пороги ⇒ их игроки
   допущены автоматически. Пользователь задал вопрос «почему?», выбор из трёх вариантов
   (оставить / задать пороги / NULL = допуска нет) НЕ сделан — уточнить!
2. Очки за ЛВК при двух ЛВК в сезоне **делятся на количество ЛВК** (среднее по ивентам).
3. Очки за рейды усредняются по числу рейд-уикендов месяца (пропущенная неделя снижает средние).
4. «Места в клане» в карточке — список по дням (`#1-2` при разделённом месте).
5. Учёт войны ЛВК игроку: война завершена ИЛИ игрок в ней атаковал.
6. Допуск проверяется по порогам клана, за который игрок играл ЛВК (не по прописке);
   не игравшие ЛВК из клана без требований — тоже автодопуск (по трём источникам:
   текущий клан / ЛВК / КВ).

## Известные факты о данных/инфраструктуре

- Upsert в `player_league` хранит лучшее показание дня (исправлено в claude/dev).
- Кэш имён (`load_and_cache_names`) — по всему семейству (исправлено в claude/dev).
